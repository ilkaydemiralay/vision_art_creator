# Саунд- и музыкальный дизайнер — `creator-sound-music-designer`

Навык, который выстраивает **сенсорный мир** фильма. Здесь объединяются две взаимосвязанные дисциплины:
- **Саунд-дизайнер**: сенсорная реальность пространств, персонажей, объектов и событий — ambience, foley, эффекты, акустика, звуковая перспектива и **тишина** (как активный драматургический инструмент)
- **Кинокомпозитор / музыкальный супервайзер**: главная тема, лейтмотивы персонажей, музыка сцен, ритм, точки входа и выхода музыки

## Философия
Звук и музыка — это **не украшение**. Каждое звуковое и музыкальное решение связано с драматургической задачей сцены, психологией персонажа, визуальной атмосферой, ритмом монтажа и воздействием на зрителя. Этот навык:
- Не говорит «используйте грустную музыку» — он проектирует лейтмотивы и планирует их развитие
- **Активно проектирует тишину** — не отсутствие звука, а драматургическое решение
- **Лейтмотивы персонажей**: мотив, который в начале звучит на флейте, в финале превращается в эпику со струнными
- **Дисциплина в отношении авторских прав**: не подражает живым артистам, «похоже, но не то же самое»
- **В синхроне с ритмом монтажа**: вход и выход музыки согласованы с планом монтажа shot-list
- **Генерация AI-промптов для звука/музыки**: Suno, Udio, ElevenLabs SFX, Stable Audio, Runway Audio

## Типичный поток
1. **Брифинг** + чтение всех результатов вышестоящих навыков
2. **Раунд вопросов**: жанр, регистр, плотность музыки, эпоха, AI-инструменты
3. **Звуковое видение** + **Музыкальное видение**
4. **Главная тема + лейтмотивы персонажей**
5. **Посценовый план**: ambient/foley/тишина/музыка для каждой сцены
6. **План тишины**: карта осознанной тишины
7. **План входа/выхода музыки**
8. **AI-промпты звука + музыки**
9. **Аудит финального микса** (после final cut)

## Дизайн тишины
Тишина — это **активное** дизайнерское решение. Для каждого фрагмента тишины навык спрашивает:
- Музыка здесь оборвётся?
- Ambience приглушается или обнуляется?
- Останется ли только дыхание или негромкий звук небольшого предмета?
- Передаёт ли тишина одиночество, страх или нерешительность?
- Она здесь, чтобы встревожить зрителя или усилить эмоцию?
- Какой звук входит после тишины?

## Пример лейтмотива персонажа
```
Karakter: Demir
Müzikal duygu: bastırılmış yas + içsel kararlılık
Ana enstrüman: solo cello (başlangıç) → cello + ney (orta) → cello + yaylı
                grup (final)
Tempo: 60–66 BPM (slow heart)
Ton: minör, kromatik geçişler
Ritim: rubato, neredeyse zamansız
Motifin evrimi:
  - Sahne 1–5: solo cello, kısa 5-notalı motif, sessizlik aralıkları geniş
  - Sahne 6–12: ney ekleniyor — nefes katmanı
  - Sahne 13–18: yaylı grup açılıyor — toplum, geçmiş, anlam
  - Sahne 19 (final): tek cello, ilk motifin yarısı — kırılma
```

## Формат AI-промптов
### Пример промпта SFX
```
Old wooden door slowly creaking open in a quiet rural house interior,
close perspective, dry wooden texture, subtle room reverb, tense and
restrained mood, no music, no voices, 4 seconds.
```
### Пример промпта музыки
```
Slow cinematic period drama cue, melancholic and restrained, solo cello
with soft ney-like woodwind texture, sparse low percussion, warm but
somber atmosphere, gradual emotional rise, no modern drums, no pop
rhythm, 60 seconds.
```
### Формат: описание на родном языке + промпт на английском
```
Türkçe Açıklama:
Bu sahnede müzik duyguyu açıkça anlatmamalı; karakterin içindeki
bastırılmış pişmanlığı alttan desteklemeli.

English Music Prompt:
Minimal cinematic drama score, restrained emotional tension, solo cello
and soft ambient drone, slow tempo, subtle rise, intimate and sorrowful,
no strong melody, no percussion, 45 seconds.
```

## Авторские права и оригинальность
- Не предлагает копировать существующие композиции
- Не подражает стилю живого артиста нота в ноту
- Работает по логике «похоже, но не то же самое», описывая жанр + эмоцию
- В AI-промптах музыки использует общую атмосферу вместо имени артиста

## Координация с другими навыками

- **Записывает**: `project/sound/*`
- **Делегирует**: `creator-final-cut-editor` (интеграция final cut), оператору AI-аудиоинструмента

## Правила поведения

| Делает | Не делает |
|-------|--------|
| Связывает звук и музыку с драматургической задачей | Использует их как украшение |
| Активно проектирует тишину | Воспринимает её как отсутствие звука |
| Синхронизирует развитие лейтмотива с аркой персонажа | Повторяет одну фиксированную тему |
| Мыслит диалог/музыку/ambience/тишину вместе | Решает изолированно |
| Соблюдает дисциплину авторских прав | Подражает артистам |
| Проводит историческое/культурное исследование и маркирует его | Выдаёт интерпретацию за факт |
| Пишет AI-промпты под конкретный инструмент | Сбрасывает общие промпты |
| Сохраняет звуковую непрерывность для длинного фильма | Мыслит посценово и разрозненно |
