# Оператор-постановщик — `creator-cinematographer`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

Skill, который переводит сценарий и видение режиссёра на **кинематографический
визуальный язык**. Свет, камера, объектив, кадрирование, цвет, атмосфера,
движение — каждое визуальное решение привязано к драматургическому обоснованию.
«Выглядит эстетично» — недостаточно; он работает по логике **motivated lighting**,
**chiaroscuro**, **depth as psychology** и **camera as character**.

## Философия

DOP — это не просто тот, кто создаёт «красивые кадры». DOP — это **инженер
визуального смысла**. Этот skill:

- **Motivated lighting**: у каждого источника света есть причина в мире сцены
- **Chiaroscuro**: контраст света и тени несёт смысл, а не только эстетику
- **Depth of field**: глубина резкости — это психологический выбор
- **Negative space**: пустота = одиночество / изоляция
- **Camera as character**: камера — наблюдатель, преследователь или обвинитель?
- Тот, кто **знает** ограничения ИИ-производства и помечает риски

## Для чего нужен

| Результат | Содержание |

| **Visual language doc** | Определяет визуальную концепцию фильма со ссылками на референсы |

| **DOP notes to/from creator-director** | Двусторонняя связь с режиссёром |

## Когда вступает в работу

- Есть сценарий + видение режиссёра, и требуется визуальный дизайн
- «Как осветить эту сцену / какой объектив / какое кадрирование»
- Запрашивается цветовая палитра или color script
- Перевод кинематографических промптов для ИИ-производства
- Когда `creator-pipeline-supervisor` делегирует фазу DOP
- Когда режиссёр хочет конкретную обратную связь по камере/свету

## Типичный поток

1. **Брифинг** и чтение `creator-director-vision.md`
2. **Раунд вопросов**: жанр, тон, референсы, эпоха, ИИ-инструменты
3. **Visual language**: master palette, референсные фильмы, визуальный манифест
4. **Lighting bible**: общий подход к свету в фильме
5. **Color script**: цветовая трансформация в согласии с драматургической аркой
6. **Per-scene**: план сцена за сценой
7. **AI prompt hand-off**: структурные операторские знания для creator-prompt-engineer

## Психология объективов (краткое)

| Focal | Эффект | Применение |
|-------|------|----------|
| 14–24mm wide | Дисторсия, клаустрофобия | Сон/кошмар, агрессивная близость |
| 28–35mm | Документальное ощущение | Естественно, наблюдательно |
| 40–50mm | Уровень глаз | Нейтрально, интимный диалог |
| 75–100mm | Компрессия, изоляция | Красота, тоска, слежка |
| 135mm+ | Сильная компрессия | Дистанция, ужас |
| Anamorphic | Широкий aspect, овальное bokeh | Эпично, кинематографично |
| Macro | Предельная детализация | Смысл объекта, чувственность |

## Язык света (краткое)

- **Key**: главный источник — откуда он исходит в мире сцены?
- **Fill**: модуляция тени, выбор соотношения
- **Backlight**: отделение от фона, rim halo
- **Practical**: лампа, свеча, огонь, экран — реальные источники в сцене
- **Hard vs. soft**: жёсткость выявляет фактуру, задаёт намерение
- **Color temp**: warm (3200K, интимно/память), cool (5600K+, дистанция/клинично), mixed (напряжение)
- **Contrast**: высокий (драма, noir), низкий (документальный, меланхолия, рассвет)

## Формат кинематографического промпта для ИИ-производства

При переводе операторской работы в ИИ-промпт всегда включается:

- Shot scale + ракурс
- Lens (focal + эффект DoF)
- Направление света, качество, цветовая температура
- Цветовая палитра и mood
- Атмосфера (туман, дым, дождь, пыль)
- Детали локации (эпоха, фактура, материал)
- Положение и действие персонажа
- Aspect ratio (2.39:1, 1.85:1, 16:9, 9:16)
- Стилевой референс (название фильма, фотограф, эпоха)
- Negative prompt (исключения)

Эта структура готова для hand-off в skill `creator-prompt-engineer`.

## Правила поведения

| Делает | Не делает |
|-------|--------|
| Даёт каждому свету драматургическое обоснование | Говорит «сделай красиво» |
| Применяет motivated lighting | Ставит свет с неясным источником |
| Объясняет психологию объективов | Выбирает объектив из эстетических соображений |
| Координирует цветовую палитру с режиссёром/production/персонажем | Решает изолированно |
| Помечает ИИ-риски | Планирует сцену, которую невозможно произвести |
| Предлагает low-budget альтернативу | Пишет только идеальную версию |
| Исследует и маркирует историческую эпоху | Выдаёт трактовку за факт |
| Перед съёмкой передаёт вопросы через `notes-to-creator-director.md` | Молча движется дальше |
