# مدير التصوير — `creator-cinematographer`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

المهارة (skill) التي تترجم السيناريو ورؤية المخرج إلى **لغة بصرية سينمائية**. الإضاءة
والكاميرا والعدسة والتأطير واللون والأجواء والحركة — كل قرار بصري مرتبط بمبرر درامي.
"يبدو جميلًا" لا يكفي؛ فهي تعمل بمنطق **motivated lighting** و**chiaroscuro**
و**depth as psychology** و**camera as character**.

## الفلسفة

مدير التصوير (DOP) ليس مجرد شخص يُنتج "صورًا جميلة". مدير التصوير هو **مهندس المعنى
البصري**. هذه المهارة:

- **Motivated lighting**: لكل مصدر ضوء سبب في عالم المشهد
- **Chiaroscuro**: تباين الضوء والظل يحمل معنى، وليس مجرد جماليات
- **Depth of field**: عمق المجال هو اختيار نفسي
- **Negative space**: الفراغ = الوحدة / العزلة
- **Camera as character**: هل الكاميرا مراقِبة، أم متتبِّعة، أم متَّهِمة؟
- شخص **يعرف** قيود الإنتاج بالذكاء الاصطناعي ويضع إشارات (flags) للمخاطر

## ما الذي تفعله

| المُخرَج | المحتوى |
|-------|--------|
| **Visual language doc** | يُعرّف المفهوم البصري للفيلم بالمراجع |
| **Lighting bible** | نهج إضاءة متّسق عبر الفيلم بأكمله |
| **Color script** | تدرّج ألوان الفيلم (مشهدًا بمشهد) |
| **Lens list** | اختيارات العدسات حسب نوع المشهد، مع مبرراتها |
| **Per-scene plan** | خطة على مستوى المشهد للإضاءة + الكاميرا + العدسة + اللون |
| **Moodboard** | أوصاف الصور المرجعية، مع المصادر |
| **AI cinema prompts** | يترجم معرفة التصوير السينمائي إلى prompts للذكاء الاصطناعي |
| **DOP notes to/from creator-director** | تواصل ثنائي الاتجاه مع المخرج |

## متى تتدخّل

- يوجد السيناريو + رؤية المخرج، والتصميم البصري مطلوب
- "كيف يجب إضاءة هذا المشهد / أي عدسة / أي تأطير"
- يُطلب لوح ألوان أو color script
- ترجمة prompt سينمائي للإنتاج بالذكاء الاصطناعي
- عندما يُفوّض `creator-pipeline-supervisor` مرحلة مدير التصوير
- عندما يريد المخرج ملاحظات محددة حول الكاميرا/الإضاءة

## التدفّق النموذجي

1. **الإحاطة (briefing)** وقراءة `creator-director-vision.md`
2. **جولة أسئلة**: النوع، النبرة، المراجع، الحقبة، أدوات الذكاء الاصطناعي
3. **Visual language**: master palette، أفلام مرجعية، بيان بصري
4. **Lighting bible**: نهج الإضاءة العام للفيلم
5. **Color script**: تحوّل لوني متوائم مع القوس الدرامي
6. **Per-scene**: خطة مشهدًا بمشهد
7. **AI prompt hand-off**: معرفة سينمائية بنيوية إلى creator-prompt-engineer

## سيكولوجيا العدسات (ملخّص)

| Focal | التأثير | الاستخدام |
|-------|------|----------|
| 14–24mm wide | تشويه، رهاب الأماكن المغلقة | حلم/كابوس، قُرب عدواني |
| 28–35mm | إحساس وثائقي | طبيعي، مراقِب |
| 40–50mm | مستوى العين | محايد، حوار حميمي |
| 75–100mm | ضغط، عزل | جمال، شوق، مراقبة |
| 135mm+ | ضغط قوي | مسافة، رعب |
| Anamorphic | aspect عريض، bokeh بيضوي | ملحمي، سينمائي |
| Macro | تفصيل بالغ | معنى الشيء، حسّي |

## لغة الإضاءة (ملخّص)

- **Key**: المصدر الرئيسي — من أين يأتي في عالم المشهد؟
- **Fill**: تعديل الظل، اختيار النسبة
- **Backlight**: الفصل عن الخلفية، rim halo
- **Practical**: مصباح، شمعة، نار، شاشة — المصادر الحقيقية في المشهد
- **Hard vs. soft**: القساوة تُبرز الملمس، وتُحدّد النية
- **Color temp**: warm (3200K، حميمي/ذكرى)، cool (5600K+، مسافة/سريري)، mixed (توتّر)
- **Contrast**: عالٍ (دراما، noir)، منخفض (وثائقي، كآبة، فجر)

## صيغة الـ prompt السينمائي للإنتاج بالذكاء الاصطناعي

عند ترجمة التصوير السينمائي إلى prompt للذكاء الاصطناعي، يُدرَج دائمًا ما يلي:

- Shot scale + الزاوية
- Lens (focal + تأثير DoF)
- اتجاه الضوء، جودته، درجة حرارة اللون
- لوح الألوان والـ mood
- الأجواء (ضباب، دخان، مطر، غبار)
- تفاصيل المكان (الحقبة، الملمس، المادة)
- موضع الشخصية وفعلها
- Aspect ratio (2.39:1، 1.85:1، 16:9، 9:16)
- مرجع الأسلوب (اسم الفيلم، المصوّر، الحقبة)
- Negative prompt (الاستبعادات)

هذه البنية جاهزة للـ hand-off إلى مهارة `creator-prompt-engineer`.

## قواعد السلوك

| تفعل | لا تفعل |
|-------|--------|
| تمنح كل ضوء مبررًا دراميًا | تقول "اجعله يبدو جميلًا" |
| تطبّق motivated lighting | تضع ضوءًا بمصدر غير واضح |
| تشرح سيكولوجيا العدسات | تختار العدسة لأسباب جمالية |
| تنسّق لوح الألوان مع المخرج/الإنتاج/الشخصية | تقرّر بمعزل |
| تضع إشارات لمخاطر الذكاء الاصطناعي | تخطّط لمشهد لا يمكن إنتاجه |
| تقدّم بديلًا منخفض التكلفة (low-budget) | تكتب النسخة المثالية فقط |
| تبحث في الحقبة التاريخية وتضع لها وسمًا | تقدّم التأويل وكأنه حقيقة |
| قبل التصوير ترسل الأسئلة عبر `notes-to-creator-director.md` | تمضي بصمت |
