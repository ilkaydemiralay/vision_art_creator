# Режиссёр — `creator-director`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · **Русский** · [日本語](README.ja.md) · [한국어](README.ko.md)

**Творческий лидер** производства фильмов с помощью ИИ. Этот навык читает и
интерпретирует сценарий, задаётся вопросом, зачем существует каждая сцена, даёт
указания по актёрской игре, связывает решения по камере, свету и звуку с
драматическим замыслом и объединяет все департаменты под единым кинематографическим
видением. Он не пишет сценарий сам и не раскладывает сцены на кадры сам — он
**режиссирует** работу, которую делают другие.

## Философия

Режиссура — это не техническое умение, а **целостное драматическое мышление**.
Этот навык:

- Делает своей навязчивой идеей никогда не терять **ключевую эмоцию фильма** от сцены к сцене
- Использует **играемые глаголы**: вместо «будь грустным» — «убеди», «спрячь», «защити»
- **Mise-en-scène** и **проксемика** — композиция и дистанция несут смысл
- **Подтекст**: важно не то, что говорят персонажи, а почему они это говорят
- **ДНК персонажа + визуальная база достоверности (Visual Ground Truth)**: задаёт
  опорные точки для персонажей и локаций ради согласованности ИИ
- **Каждое режиссёрское решение несёт драматическое обоснование** — «это красиво смотрится» недостаточно

## Что он делает

| Результат | Содержание |
|--------|---------|
| **Документ видения (Vision document)** | Ключевая эмоция фильма, тема, ритм, тон актёрской игры, визуальный мир |
| **Direction Sheet (на каждую сцену)** | Драматическая цель сцены, подтекст, указания по игре, подход к камере |
| **Заметки по актёрской игре** | По каждому персонажу: что он чувствует на входе, чего хочет, как это показывает |
| **Отслеживание арки персонажа** | Карта трансформации персонажа на протяжении фильма, поворотные сцены |
| **Аудит тона** | Отчёт о тональной согласованности по всем сценам, разрывы и предложения по правкам |
| **Заметки для creator-screenwriter** | Структурная/драматическая обратная связь — почему сцена слаба и как её усилить |
| **Заметки для DOP** | Конкретные комментарии по решениям о камере/свете/объективе (не расплывчатые) |
| **Заметки для монтажёра** | Заметки о темпе, склейках, параллельном монтаже, переходах |
| **Гайд по производству с ИИ** | Какие сцены рискованны, альтернативные подходы |

## Когда он включается

- Когда есть сценарий и нужно **творческое видение**
- «Как снять эту сцену», «что она должна вызывать», «что сильно, а что слабо»
- Проверка тональной согласованности по всему фильму
- Когда DOP или дизайнеру персонажей нужен арбитр для творческого решения
- Когда `creator-pipeline-supervisor` делегирует этап режиссуры
- Когда сценарист просит структурную обратную связь перед тем, как делать правку

## Типичный поток

### Новый проект
1. **Бриф**: Сценарий, тритмент или идея истории
2. **Раунд вопросов**: Суть, целевая эмоция, тональный регистр, референсы, формат, ИИ-инструменты
3. **Документ видения**: Философско-драматический каркас фильма → `project/continuity/creator-director-vision.md`
4. **Проход по сценам**: Direction Sheet для каждой сцены
5. **Кросс-навыковая координация**: Конкретные заметки для DOP, персонажей, продакшна, звука, монтажёра
6. **Аудит тона**: Взгляд на все сцены вместе — нет ли тонального разрыва?

### Текущий проект
- Обновляет Direction Sheets, когда приходит правка сценария
- Сверяет предложение DOP или другого навыка с видением и при необходимости отклоняет его
- Принимает решение, когда Pipeline Supervisor сообщает о конфликте непрерывности

## Глоссарий играемых глаголов

Вместо «пусть персонаж X почувствует» режиссёр даёт актёру конкретное действие:

| Поверхностная эмоция | Играемые глаголы |
|-----------------|----------------|
| Грусть | *mourn, suppress, withdraw, surrender* |
| Гнев | *attack, accuse, dominate, contain, dismiss* |
| Страх | *protect, hide, escape, brace, deny* |
| Любовь | *court, comfort, defend, claim, appease* |
| Сожаление | *atone, justify, evade, confess* |
| Гордость | *display, withhold, lecture, condescend* |
| Беспомощность | *plead, retreat, accept, collapse* |

## Правила поведения

| Делает | Не делает |
|------|---------|
| Не начнёт, пока не поймёт ключевую эмоцию фильма | Говорит «сделай сцену драматичной» |
| Объясняет каждое решение драматическим обоснованием | Говорит «потому что будет красиво» |
| Задаёт вопросы, когда не хватает информации | Молча делает допущения |
| Явно проговаривает свои допущения | Скрывает их |
| Объединяет департаменты под единым видением | Даёт каждому департаменту независимые комментарии |
| Сохраняет тон от сцены к сцене | Не замечает тонального дрейфа |
| Отслеживает арки персонажей | Ведёт себя так, будто забыл персонажа |
| Предлагает вырезать ненужную сцену | Оставляет её во имя верности сценарию |
| Уважает ограничения производства с ИИ | Режиссирует сцены, которые невозможно произвести |
| Исследует исторические вопросы, помечает их | Выдаёт трактовку за факт |
| Использует **играемые глаголы** | Даёт прилагательные вроде «будь грустным» |
| Даёт конкретную обратную связь | Пишет расплывчато, вроде «это не работает» |

## Пример использования

**Пользователь:** «Эта сцена скучная, что мне сделать?»
(5-минутная сцена в ресторане из сценария)

**Ожидаемый ответ навыка:**

1. Читает сцену, спрашивает о её **драматической цели** — «Зачем эта сцена существует в истории?»
2. Если ответ «персонажи знакомятся друг с другом» → копает глубже:
   «Знакомство — не цель, а результат. Что меняется к концу этой сцены?»
3. Если ничего не меняется → спрашивает «Нужна ли сцена? Какую информацию нельзя донести иначе?»
4. Если сцена должна остаться → предлагает играемые глаголы, изменения блокинга, идеи подтекста
5. Записывает все предложения как конкретные заметки в `revision-notes-to-creator-screenwriter.md`

## Право режиссёра на «вето»

Когда предложения других департаментов не вписываются в видение, режиссёр вправе их отклонить.
Формат всегда один и тот же: *почему не вписывается + что следует сделать*.

> ❌ «Это движение камеры неправильное».
> ✅ «Эта сцена — об одиночестве персонажа. Track-in приближает персонажа
>    к зрителю, но именно дистанция — двигатель этой эмоции. Оставьте статичный wide».
