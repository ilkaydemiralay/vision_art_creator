# Дизайнер шот-листа — `creator-shot-list-designer`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · **Русский** · [日本語](README.ja.md) · [한국어](README.ko.md)

Скилл, который превращает сцены и раскадровки в **шот-лист + монтажный замысел**.
Место, где сходятся планирование препродакшена и редакторский замысел. Это
не финальный монтажёр — он проектирует монтажный замысел ДО того, как произведён
какой-либо материал, чтобы съёмка генерировала нужные фрагменты.

## Философия

Шот-лист — это не технический перечень; это **карта драматического + монтажного
замысла**. Этот скилл:

- **Экономия shot'ов**: каждый shot несёт одно ясное действие
- **Чувство монтажного ритма**: какой shot держится долго, какой режется быстро?
  Длительность shot'а — это монтажное решение
- **Направление взгляда на экране + непрерывность**: пространственная/временная согласованность между cut'ами
- **Производимость для AI**: планирует сложность одиночного shot'а с учётом ограничений AI-инструментов
- **Монтажный замысел до производства**: логика монтажа задаётся ДО съёмки,
  чтобы не снимались ненужные shot'ы
- **Дизайн зрительского опыта**: что зритель чувствует, узнаёт, и что от него утаивается?

## Что он производит

| Результат | Содержание |
|-------|---------|
| **Шот-лист по каждой сцене** | Канонический шот-лист с драматическим + монтажным обоснованием |
| **План монтажа** | Внутрисценный темпоритм, точки cut'а, открывающий/закрывающий кадр |
| **Дизайн transition'ов** | Решения о переходах между сценами (hard cut, match, J/L, sound bridge) |
| **Аудит рисков непрерывности** | Отчёт о рисках согласованности между shot'ами |
| **Заметки по звуковому монтажу** | Точки J-cut / L-cut / тишины для звукорежиссёра |
| **Шот-лист по всему фильму** | Сводный список, охватывающий весь фильм |
| **Карта ритма** | Темпоритм по сценам (диапазоны длительности shot'ов) |
| **Отчёт об избыточности** | Shot'ы, которые следует вырезать/объединить |
| **Заметки для финального монтажёра** | Передача монтажного замысла финальному монтажёру |

## Когда он вступает в дело

- Сцены и раскадровки готовы, и нужен план на основе shot'ов
- Запрошено выстраивание shot'ов с учётом монтажа
- Длинные сцены нужно разбить на производимые в AI фрагменты
- Когда режиссёр или DOP запрашивает структурный план съёмки/производства
- Когда `creator-pipeline-supervisor` делегирует предмонтажное планирование

## Типичный поток

1. **Бриф** + чтение всех результатов вышестоящих скиллов
2. **Раунд вопросов**: формат, монтажный ритм, тон, AI-инструменты
3. **Шот-лист (по сцене)**: в канонической структуре, с драматическим + монтажным обоснованием
4. **План монтажа (по сцене)**: темпоритм, открытие/закрытие, точки cut'а
5. **Дизайн transition'ов**: переходы между сценами
6. **Аудит непрерывности**: межшотовые риски
7. **Карта ритма**: карта темпоритма по всему фильму
8. **Отчёт об избыточности**: выявление shot'ов, которые можно вырезать
9. **Передача**: данные prompt'ов shot'ов для creator-prompt-engineer + монтажный замысел для creator-final-cut-editor

## Shot — каноническая структура

```
Scene 04 — Shot 04.02
Shot name: "Kettle close, silence"
Shot type: insert
Frame scale: extreme close
Camera angle: eye level (side-high)
Camera movement: static
Lens recommendation: 100mm macro feeling
Estimated duration: 4s
Location: Anatolian kitchen 1980s [anchor: kitchen-anatolian-1980s]
Time: night
Characters in frame: none (only the kettle)
Character action: kettle whistle dying down (off-screen Demir turns off the heat)
Dialogue / silence note: SILENCE (only kettle + clock ticking)
Light / atmosphere: gray moonlight from the window, copper kettle highlight
Sound / music note: NO music; clock ticking + kettle dying
Dramatic purpose: a symbolic echo of Demir's inner turning
Edit purpose: a 4-second breath — no need to cut, hold it
Link to previous shot: 04.01 (Demir sitting, wide) — match by sound
Link to next shot: 04.03 (Demir's face close, first blink) — hard cut
Continuity note: kettle = same copper, same stain pattern
AI video production note: single action (whistle dying) + static camera = low risk
Safe alternative: 6s version — slower whistle fade, very slow camera push-in
```

## Монтажный замысел — план сцены

Монтажные вопросы на уровне сцены:

- Какой shot открывает сцену?
- Какой кадр её закрывает?
- Какой shot держится долго?
- Какой shot режется коротко?
- Куда идут reaction shot'ы?
- Где тишина растягивается?
- Где нужен hard cut?
- Где мягкий transition?
- Какой кадр связывает со следующей сценой?
- Какой shot несёт драматический пик?
- Какой shot не нужен?
- Какой shot доносит информацию, а какой — эмоцию?

Записывается в `project/shot-list/scene-{NN}/edit-plan.md`.

## Типы transition'ов (монтажное применение)

| Transition | Монтажное применение |
|-------|-------------------|
| Hard cut | Резкий драматический разрыв |
| Match cut | Смысловой мост между двумя кадрами |
| Fade in/out | Временно́е/эмоциональное открытие/закрытие |
| Dissolve | Переход во времени, эмоциональное смешение |
| J-cut | Звук следующей сцены приходит первым (плавное течение) |
| L-cut | Звук текущей сцены продлевается (удержанная эмоция) |
| Sound bridge | Смена места/времени, перенесённая звуком |
| Visual motif | Мост через повторяющийся визуальный образ |
| Object transition | Совпадение по форме |
| Movement transition | Направленная непрерывность |
| Time jump | Резкий скачок во времени |
| Flashback | Через фильтр/линзу/размытие/звуковой акцент |
| Parallel edit | Два места, переплетённые между собой |

## Правила производимости AI-видео

- Одно ясное действие на shot
- Одно основное движение камеры (не цепочкой)
- Контролируемое число персонажей
- Ясная визуальная цель
- Разбивай сложное движение на несколько shot'ов
- Помечай рискованные руки/пальцы/lip sync
- Избирательное кадрирование для толпы
- Зафиксированные anchor'ы локации + персонажей в каждом prompt'е
- Длительность shot'а обычно 3–10s
- Каждый shot чисто отображается в один видео-prompt

Когда обнаружен риск, помечай его:

> *"Этот shot слишком сложен для AI-видео — раздели его на два shot'а."*
> *"Здесь lip sync может не сработать; используй reaction shot вместо говорящего."*
> *"Движение руки критично — используй более широкий кадр вместо insert'а."*
> *"Действие толпы — выстраивай его cut'ами, а не одним shot'ом."*

## Ритм и темпоритм

Расплывчатые фразы вроде «сделай быстро» не используются. Темпоритм:

- Выражается как **диапазон длительности shot'ов**
- Измеряется по **частоте cut'ов**

Пример:
> *"Сцена 3 в среднем 4–6s/shot, сцена 12 в среднем 1.5–3s/shot —
> темп ускоряется по мере нарастания конфликта персонажа."*

## Монтажный замысел диалога

Для сцен, насыщенных диалогом:

- Говорящий или слушающий?
- Куда идут reaction shot'ы?
- Где тишина сильнее?
- Другой кадр поверх диалога?
- Подтекст через выражение лица?
- Hard cut против естественного наложения?
- Cut до того, как фраза закончится?
- Избыточное повторение объяснения?
- На ком та эмоция, которую зрителю действительно нужно увидеть?

Маркеры J-cut / L-cut задаются здесь.

## Координация с другими скиллами

- **Читает**: сценарий, видение режиссёра + листы постановки, посценный план DOP,
  данные панелей раскадровки, anchor'ы персонажей/локаций
- **Пишет**: `project/shot-list/*`
- **Передаёт**:
  - `creator-prompt-engineer` (видео-prompt'ы на уровне shot'а)
  - `creator-final-cut-editor` (файлы монтажного замысла)
- **Получает обратную связь от**: Режиссёра, Pipeline Supervisor

## Обнаружение избыточности

В длинном AI-фильме помечай:

- Shot, повторяющий ту же информацию
- Shot, не меняющий эмоцию
- Детальный shot, сбивающий ритм
- Чрезмерное использование reaction shot'ов
- Тяжёлый для AI shot с низким драматическим вкладом
- Возможности позднего входа / раннего выхода
- Момент, который можно рассказать визуально, а не диалогом

*"Этот shot можно вырезать"* или *"Эти два shot'а можно объединить"* пишется явно.

## Поведенческие правила

| Делает | Не делает |
|-------|---------|
| Даёт каждому shot'у драматическое **и** монтажное обоснование | Составляет технический перечень |
| Координируется с ритмом режиссёра, кадрированием DOP, раскадровкой | Решает в изоляции |
| Помечает ненужные shot'ы | Добавляет наполнитель |
| Проактивно проверяет непрерывность | Ждёт, пока проблемы всплывут после съёмки |
| Проектирует с учётом ограничений AI-инструментов | Планирует непроизводимые shot'ы |
| Безопасная альтернатива для рискованных shot'ов | Даёт единственную версию |
| Учитывает и слушающего в диалоге | Следует только за говорящим |
| Координирует монтажный замысел звука и музыки | Думает только о картинке |
| Структурированный, читаемый ниже по потоку результат | Вываливает единый блок текста |
