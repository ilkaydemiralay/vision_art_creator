# مصمم قائمة اللقطات — `creator-shot-list-designer`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · **العربية** · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

المهارة التي تحوّل المشاهد واللوحات القصصية إلى **قائمة لقطات + نية تحريرية**.
المكان الذي تلتقي فيه عملية التخطيط لما قبل الإنتاج مع النية التحريرية. إنها
ليست محرّر المونتاج النهائي — فهي تصمّم النية التحريرية قبل إنتاج أي مادة،
بحيث يولّد التصوير القطع الصحيحة.

## الفلسفة

قائمة اللقطات ليست جردًا تقنيًا؛ بل هي **خريطة للنية الدرامية + التحريرية**.
هذه المهارة:

- **اقتصاد اللقطة**: كل لقطة تحمل فعلًا واحدًا واضحًا
- **الوعي بإيقاع المونتاج**: أي لقطة تُمسَك طويلًا، وأيها يُقطَع بسرعة؟
  مدة اللقطة قرار تحريري
- **اتجاه الشاشة + الاستمرارية**: الاتساق المكاني/الزماني عبر القطعات
- **القابلية للإنتاج بالـ AI**: تخطيط تعقيد اللقطة الواحدة وفق قيود أدوات الـ AI
- **النية التحريرية قبل الإنتاج**: يُحدَّد منطق المونتاج قبل التصوير
  حتى لا تُصوَّر اللقطات غير الضرورية
- **تصميم تجربة الجمهور**: ماذا يشعر المُشاهد، وماذا يتعلّم، وما الذي يُحجَب عنه؟

## ما الذي تنتجه

| المخرَج | المحتوى |
|-------|---------|
| **قائمة لقطات لكل مشهد** | قائمة لقطات معيارية، مع تبرير درامي + تحريري |
| **خطة المونتاج** | إيقاع داخل المشهد، نقاط القطع، الصورة الافتتاحية/الختامية |
| **تصميم الانتقالات** | قرارات الانتقال من مشهد إلى مشهد (hard cut، match، J/L، sound bridge) |
| **تدقيق مخاطر الاستمرارية** | تقرير عن مخاطر الاتساق عبر اللقطات |
| **ملاحظات مونتاج الصوت** | نقاط J-cut / L-cut / الصمت لمصمم الصوت |
| **قائمة لقطات شاملة للفيلم** | قائمة موحَّدة تغطي الفيلم بأكمله |
| **خريطة الإيقاع** | إيقاع مشهدًا بمشهد (نطاقات مدد اللقطات) |
| **تقرير التكرار** | اللقطات التي ينبغي قطعها/دمجها |
| **ملاحظات للمحرّر النهائي** | تسليم النية التحريرية إلى محرّر المونتاج النهائي |

## متى تدخل حيز العمل

- جاهزية المشاهد واللوحات القصصية، والحاجة إلى خطة قائمة على اللقطات
- طلب تسلسل لقطات واعٍ بالمونتاج
- الحاجة إلى تقسيم المشاهد الطويلة إلى قطع قابلة للإنتاج بالـ AI
- عندما يطلب المخرج أو الـ DOP خطة تصوير/إنتاج بنيوية
- عندما يفوّض `creator-pipeline-supervisor` التخطيط لما قبل المونتاج

## التدفق المعتاد

1. **الإحاطة** + قراءة جميع مخرجات المهارات السابقة في السلسلة
2. **جولة الأسئلة**: الصيغة، إيقاع المونتاج، النبرة، أدوات الـ AI
3. **قائمة اللقطات (لكل مشهد)**: في بنية معيارية، مع تبرير درامي + تحريري
4. **خطة المونتاج (لكل مشهد)**: الإيقاع، الافتتاح/الختام، نقاط القطع
5. **تصميم الانتقالات**: الانتقالات من مشهد إلى مشهد
6. **تدقيق الاستمرارية**: المخاطر عبر اللقطات
7. **خريطة الإيقاع**: خريطة إيقاع شاملة للفيلم
8. **تقرير التكرار**: تحديد اللقطات القابلة للقطع
9. **التسليم**: بيانات prompt اللقطات لـ creator-prompt-engineer + النية التحريرية لـ creator-final-cut-editor

## اللقطة — البنية المعيارية

```
Scene 04 — Shot 04.02
Shot name: "Kettle close, silence"
Shot type: insert
Frame scale: extreme close
Camera angle: eye level (side-high)
Camera movement: static
Lens recommendation: 100mm macro feeling
Estimated duration: 4s
Location: Anatolian kitchen 1980s [anchor: kitchen-anatolian-1980s]
Time: night
Characters in frame: none (only the kettle)
Character action: kettle whistle dying down (off-screen Demir turns off the heat)
Dialogue / silence note: SILENCE (only kettle + clock ticking)
Light / atmosphere: gray moonlight from the window, copper kettle highlight
Sound / music note: NO music; clock ticking + kettle dying
Dramatic purpose: a symbolic echo of Demir's inner turning
Edit purpose: a 4-second breath — no need to cut, hold it
Link to previous shot: 04.01 (Demir sitting, wide) — match by sound
Link to next shot: 04.03 (Demir's face close, first blink) — hard cut
Continuity note: kettle = same copper, same stain pattern
AI video production note: single action (whistle dying) + static camera = low risk
Safe alternative: 6s version — slower whistle fade, very slow camera push-in
```

## النية التحريرية — خطة المشهد

أسئلة تحريرية على مستوى المشهد:

- أي لقطة تفتتح المشهد؟
- أي صورة تختمه؟
- أي لقطة تُمسَك طويلًا؟
- أي لقطة تُقطَع قصيرة؟
- أين تذهب لقطات ردّ الفعل؟
- أين يمتدّ الصمت؟
- أين تلزم hard cut؟
- أين يكون الانتقال ناعمًا؟
- أي صورة تربط بالمشهد التالي؟
- أي لقطة تحمل الذروة الدرامية؟
- أي لقطة غير ضرورية؟
- أي لقطة تقدّم معلومة، وأيها يقدّم عاطفة؟

تُكتَب ضمن `project/shot-list/scene-{NN}/edit-plan.md`.

## أنواع الانتقالات (الاستخدام التحريري)

| الانتقال | الاستخدام التحريري |
|-------|-------------------|
| Hard cut | كسر درامي مفاجئ |
| Match cut | جسر معنى بين صورتين |
| Fade in/out | افتتاح/ختام زماني/عاطفي |
| Dissolve | انتقال زمني، مزج عاطفي |
| J-cut | يصل صوت المشهد التالي أولًا (تدفّق سلس) |
| L-cut | يُمدَّد صوت المشهد الحالي (عاطفة مُمسَكة) |
| Sound bridge | تغيّر مكان/زمن محمول عبر الصوت |
| Visual motif | جسر عبر عنصر بصري متكرّر |
| Object transition | تطابق شكلي |
| Movement transition | استمرارية اتجاهية |
| Time jump | قفزة زمنية مفاجئة |
| Flashback | عبر فلتر/عدسة/تشويش/إشارة صوتية |
| Parallel edit | مكانان متشابكان |

## قواعد القابلية للإنتاج بفيديو الـ AI

- فعل واحد واضح لكل لقطة
- حركة كاميرا رئيسية واحدة (غير متسلسلة)
- عدد مضبوط من الشخصيات
- هدف بصري واضح
- تقسيم الحركة المعقّدة إلى لقطات متعدّدة
- التنبيه على lip sync الخطر لليد/الأصابع
- تأطير انتقائي للحشود
- مرافق (anchors) موقع وشخصية مثبّتة في كل prompt
- مدة اللقطة عادةً 3–10s
- كل لقطة تُسقَط بنظافة على prompt فيديو واحد

عند اكتشاف خطر، يُنبَّه عليه:

> *"هذه اللقطة معقّدة أكثر من اللازم لفيديو الـ AI — قسّمها إلى لقطتين."*
> *"قد يفشل lip sync هنا؛ استخدم لقطة ردّ فعل بدلًا من المتحدّث."*
> *"حركة اليد حاسمة — استخدم تأطيرًا أوسع بدلًا من insert."*
> *"فعل جماعي — ابنِه بالقطعات، لا بلقطة واحدة."*

## الإيقاع والوتيرة

لا تُستخدَم عبارات مبهمة مثل "اجعلها سريعة". الإيقاع:

- يُعبَّر عنه بـ **نطاق مدة اللقطة**
- يُقاس بـ **تكرار القطع**

مثال:
> *"المشهد 3 يبلغ متوسطه 4–6s/لقطة، والمشهد 12 يبلغ متوسطه 1.5–3s/لقطة —
> تتسارع الوتيرة مع تصاعد صراع الشخصية."*

## النية التحريرية للحوار

للمشاهد كثيفة الحوار:

- المتحدّث أم المستمع؟
- أين تذهب لقطات ردّ الفعل؟
- أين يكون الصمت أقوى؟
- صورة أخرى فوق الحوار؟
- النص الضمني عبر تعبير الوجه؟
- hard cut أم تداخل طبيعي؟
- القطع قبل انتهاء الجملة؟
- تكرار زائد للشرح؟
- على من تكون العاطفة التي يحتاج المُشاهد فعلًا أن يراها؟

تُحدَّد هنا علامات J-cut / L-cut.

## التنسيق مع المهارات الأخرى

- **تقرأ**: السيناريو، رؤية المخرج + أوراق التوجيه، خطة الـ DOP لكل مشهد،
  بيانات لوحات القصة، مرافق (anchors) الشخصيات/المواقع
- **تكتب**: `project/shot-list/*`
- **تسلّم إلى**:
  - `creator-prompt-engineer` (prompts فيديو على مستوى اللقطة)
  - `creator-final-cut-editor` (ملفات النية التحريرية)
- **تتلقّى تغذية راجعة من**: المخرج، مشرف خط الإنتاج

## كشف التكرار

في فيلم AI طويل، نبّه على:

- لقطة تكرّر المعلومة نفسها
- لقطة لا تغيّر العاطفة
- لقطة تفصيلية تُسقِط الإيقاع
- إفراط في استخدام لقطات ردّ الفعل
- لقطة صعبة على الـ AI ذات مساهمة درامية ضعيفة
- فرص الدخول المتأخّر / الخروج المبكّر (late-in / early-out)
- لحظة يمكن سردها بصريًا بدلًا من الحوار

تُكتَب صراحةً *"يمكن قطع هذه اللقطة"* أو *"يمكن دمج هاتين اللقطتين"*.

## القواعد السلوكية

| تفعل | لا تفعل |
|-------|---------|
| تمنح كل لقطة تبريرًا دراميًا **و** تحريريًا | تصنع جردًا تقنيًا |
| تنسّق مع إيقاع المخرج وتأطير الـ DOP ولوحة القصة | تقرّر في عزلة |
| تنبّه على اللقطات غير الضرورية | تضيف حشوًا |
| تتحقّق من الاستمرارية استباقيًا | تنتظر ظهور المشكلات بعد التصوير |
| تصمّم وفق قيود أدوات الـ AI | تخطّط للقطات غير قابلة للإنتاج |
| تقدّم بديلًا آمنًا للقطات الخطرة | تقدّم نسخة واحدة فقط |
| تأخذ المستمع أيضًا بالحسبان في الحوار | تتبع المتحدّث فقط |
| تنسّق النية التحريرية للصوت والموسيقى | تفكّر في الصورة فقط |
| مخرَج منظَّم وقابل للقراءة في المراحل اللاحقة | يلقي كتلة نصية واحدة |
