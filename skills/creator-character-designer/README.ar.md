# مصمّم الشخصيات — `creator-character-designer`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

مهارة ترتقي بالشخصية إلى ما هو أبعد من ثلاثية **الاسم + العمر + المظهر** وتصمّمها
ككائن **متكامل**. تنتج الوظيفة الدرامية، وعلم النفس، والسيرة، ولغة الجسد، والأزياء،
والـ props، وملف الكاستينغ، إضافةً إلى **مكتبة تعبيرات مُرمَّزة بأكواد FACS Action
Unit**. وتُرسي مرتكزات «Character DNA» التي تحافظ على اتّساق الشخصية عبر إنتاج
الأفلام بالذكاء الاصطناعي طويل الأمد.

## الفلسفة

لا تُولَّد الشخصية عشوائيًا — بل تنبثق من حاجة السيناريو، ورؤية المخرج، والعالم
البصري للـ DOP. هذه المهارة:

- **كل شخصية هي إجابة عن سؤال درامي** — وإلّا فإنها تقترح حذف الشخصية
- تُرسي إلزاميًا رباعية **Want / Need / Fear / Wound** لكل شخصية رئيسية
- **FACS Action Units**: بدلًا من قول «حزين»، تقول AU1+AU4+AU15 —
  فنماذج الذكاء الاصطناعي والمحرّكون يفسّرون الكود التشريحي بصورة أكثر اتّساقًا
- **Character DNA**: تُعرّف سمات مرتكزة مقفلة من أجل اتّساق الذكاء الاصطناعي
- **Visual distinction audit**: عند وجود عدّة شخصيات، تدقّق في تمايزات الصورة الظلّية واللون والطاقة

## ما الذي تفعله

| المخرَج | المحتوى |
|---------|---------|
| **Character sheet** | ملف الشخصية — علم النفس، الأزياء، الـ prop، FACS، الـ AI prompt |
| **Costume bible** | تنويعات الأزياء واستمراريتها عبر الفيلم بأكمله |
| **Props list** | الأغراض الشخصية للشخصية واستخداماتها الدرامية |
| **FACS expression library** | 3–5 تعبيرات مميِّزة لكل شخصية، مُرمَّزة بأكواد AU |
| **Casting brief** | الملف المطلوب في الممثّل (لا تقترح أسماء، بل تُعرّف السمات) |
| **AI prompts** | base prompt + تنويعات المشاهد لمرجع شخصية متّسق |
| **Arc tracker** | تحوّل الشخصية مُنسَّقًا مع arc tracking الخاص بالمخرج |
| **Continuity notes** | استمرارية الأزياء/الـ props مشهدًا بمشهد |

## متى تتدخّل

- السيناريو جاهز ويُراد تطوير الشخصيات
- «أعِدّ character sheet»، «صمّم زيًّا»، «اكتب ملف كاستينغ»
- يُحتاج إلى مرجع شخصية متّسق لفيلم بالذكاء الاصطناعي
- عندما يفوّض المخرج أو `creator-pipeline-supervisor` مرحلة الشخصيات
- عندما يُطرح تساؤل حول التمايز البصري للشخصيات القائمة

## استخدام FACS — لماذا وكيف

**نظام ترميز حركات الوجه (Facial Action Coding System، Ekman & Friesen، 1978)** هو
الترميز التشريحي لعضلات الوجه. الـ Action Unit (AU) = حركة عضلية محدّدة.

### لماذا تستخدمه هذه المهارة؟

- **مولّدات الذكاء الاصطناعي** تفسّر المدخلات المجرّدة مثل «happy face» بصورة غير متّسقة؛
  أمّا «AU6 + AU12 (Duchenne smile)» فيعطي نتيجة أكثر موثوقية
- **فِرق التحريك/الـ VFX** تتشارك مجموعة مرجعية واحدة عبر أكواد AU
- **التعبير المميِّز للشخصية** يمكن توثيقه — مثلًا «يحمل Demir حزنه المكبوت
  بـ AU4 + AU17 (الجبين مقطَّب، الذقن مرفوع، بلا AU15)»

### تركيبات AU الشائعة

| التعبير | AU |
|---------|-----|
| Duchenne smile (سعادة حقيقية) | AU6 + AU12 |
| Polite smile (مزيّفة/اجتماعية) | AU12 وحدها |
| الحزن | AU1 + AU4 + AU15 |
| الغضب | AU4 + AU5 + AU7 + AU23 |
| الخوف | AU1 + AU2 + AU4 + AU5 + AU7 + AU20 + AU26 |
| الاشمئزاز | AU9 + AU15 + AU16 |
| المفاجأة | AU1 + AU2 + AU5B + AU26 |
| الاحتقار (غير متناظر) | AU12 (من جانب واحد) + AU14 |
| الحزن المكبوت | AU4 + AU17 (بلا AU15) |
| السكون المتوتّر | AU7 + AU23 + AU24 |

## قالب character sheet (موجز)

```
Character: Demir
Role: Protagonist
Want: babasının arşivini bulup yakmak
Need: kendisini babadan ayırmadan da yaşayabileceğini görmek
Fear: babasının tüm kötü yanlarına dönüşmek
Wound: 14 yaşında bir gece babasının onu fark etmemesi
Visual identity: lacivert ağır kumaş palto, traşsız, sol elinin
                 üstünde küçük yanık izi
Signature expressions:
  - Bastırılmış yas: AU4 + AU17 (mutfak sahnesinde kettle önünde)
  - Reddediş: AU14 + AU24 (kuzeniyle konuşma)
  - Saklı acı: AU1 + AU4, gözler kaçıyor (cenaze sonrası)
Continuity anchors: yanık izi, palto, traşsız, ses tonu — sessiz, alçak
AI base prompt: "...same character across all scenes..."
```

## Visual distinction audit

عند وجود أكثر من شخصية، تُجري المهارة هذه الفحوص:

- تمايز الصورة الظلّية (الطول، الوقفة، شكل الزيّ)
- تمايز العالم اللوني (أو تباين مقصود)
- تمايز سجلّ الطاقة
- تمايز نمط الكلام
- تمايز الحضور على الشاشة (نوع foreground / background)

إذا «تداخلت» شخصيتان معًا، فإنها تُبلِغ عن ذلك وتقترح مراجعة.

## اتّساق الذكاء الاصطناعي (Character DNA)

لتوليد الشخصية نفسها عبر 50 مشهدًا بالوجه/الزيّ نفسه:

1. **Base prompt** — السمات الأساسية (شكل الوجه، الشعر، العلامة المميِّزة) ثابتة
2. **Anchor descriptors** — يتكرّر 2–3 منها في كل prompt مشهدي
3. **التعبير عبر FACS** — مُرمَّز بأكواد AU، لا بالصفات
4. **إنتاج مبكّر للـ character sheet** — صور مرجعية front/side/back/close
5. **مرجع في prompt المشهد**: «consistent with `characters/demir/sheet.png`»

## منهج تصميم الأزياء

الزيّ يروي الشخصية — وليس مجرّد «ما ترتديه»:

- القطعة الرئيسية + وظيفتها
- القماش: ثقيل، ناعم، صلب، ليفي
- اللون: انسجام/تباين مع لوحة الألوان
- البلى / الجِدّة / التلف / آثار الترميم
- دقّة الحقبة الزمنية
- العلاقة بحالة الشخصية المزاجية
- الأثر على القدرة على الحركة
- التفاعل مع الضوء (مطفأ، لامع، شفّاف، يلتقط الغبار)

لكل مشهد رئيسي ملاحظة استمرارية للزيّ: هل يتغيّر داخل المشهد، هل يتغيّر بين المشاهد،
ولماذا؟

## منهج الـ props

الـ props أدوات سردية — لا زينة:

- الاسم + الوظيفة
- العلاقة بالشخصية
- المظهر، المادة، اللون، الحالة
- المعنى بالنسبة إلى الشخصية (تذكار، هوية، علاقة)
- الاستخدام الدرامي (تمهيد، استثمار، كشف)
- كيف تراه الكاميرا (لقطة قريبة، تفصيل، عابر)
- الاستمرارية (أين يقع في كل مشهد)

تُوضَّح ملكية شخصية-prop / موقع-prop، ويجري التنسيق مع
**creator-production-designer**.

## قواعد السلوك

| تفعل | لا تفعل |
|------|---------|
| تُولّد الشخصية بمسوّغ درامي | تقول «نحتاج شخصية إضافية» |
| تربط كل اختيار بصري بالـ arc / الوظيفة / الثيمة | تتّخذ اختيارات جمالية معزولة |
| تطرح أسئلة عند نقص المعلومات | تختلق بصمت |
| تبحث في التفاصيل الثقافية | تقدّم التخمين كأنه حقيقة |
| تُعرّف التعبيرات بأكواد FACS AU | تستخدم صفات مثل «حزين» |
| تُجري visual distinction audit | تترك شخصيتين تتداخلان |
| تُضمّن continuity anchors في الـ AI prompts | تصف من الصفر في كل مشهد |
| تُوضّح ملكية شخصية-prop | تتداخل مع مصمّم الإنتاج |
| تسلّم ملفات منظَّمة وقابلة للقراءة downstream | تَصبّ كتلة نصّية واحدة |
