# محرّر المونتاج النهائي — `creator-final-cut-editor`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · **العربية** · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

المهارة التي تحوّل مخرجات إنتاج الذكاء الاصطناعي إلى **فيلم مكتمل**. نهاية
مرحلة ما قبل الإنتاج / بداية مرحلة ما بعد الإنتاج. بمجرد إنتاج المواد،
تتولى إدارة مسار rough cut ← fine cut ← final cut ← التسليم؛ وتفرز أخطاء
توليد الذكاء الاصطناعي، وتدقّق الاستمرارية، وتتحقق من تكامل الصوت/الموسيقى،
وتنتج نسخًا رئيسية (masters) جاهزة للتسليم.

**الفرق عن shot-list-designer**: قائمة اللقطات تصمّم النيّة المونتاجية
قبل التصوير؛ أما creator-final-cut-editor فينفّذ المونتاج على المادة
الفعلية.

## الفلسفة

المونتاج النهائي **ليس تسلسلًا تقنيًا** — بل هو بناء
الكمال السينمائي. هذه المهارة:

- **مبرّر درامي لكل قطع** — "يبدو جيدًا" لا يكفي
- **إيقاع متعدد المقاييس**: داخل اللقطة، داخل المشهد، عبر الفيلم بأكمله
- **فرز أخطاء الذكاء الاصطناعي**: أي خطأ يُفسد المونتاج، وأيّها يمكن إخفاؤه، وأيّها يمكن أن يبقى
- **تصميم تجربة الجمهور**: ما الذي يشعر به المشاهد ويتعلمه ويخرج به
- **انضباط التسليم**: YouTube ≠ مهرجان ≠ Instagram ≠ أرشيف
- **إدارة النسخ**: تدير rough/fine/final + نسخ المهرجان/التواصل الاجتماعي/التريلر بشكل منفصل

## ما الذي تقوم به

| المخرَج | المحتوى |
|-------|---------|
| **تقييم المواد** | لكل لقطة: قابلة للاستخدام / تحتاج مراجعة / إعادة توليد / قطع |
| **خطة rough cut** | تسلسل أولي تقريبي، قائمة بالمواد الناقصة |
| **خطة fine cut** | نقاط القطع، مدد اللقطات، الصمت |
| **خطة final cut** | جاهزية نهائية + قائمة تحقق للتسليم |
| **التدقيق النهائي لكل مشهد** | تدقيق تفصيلي مشهدًا بمشهد |
| **تقرير الفيلم بأكمله** | تقرير المونتاج النهائي للفيلم كاملًا |
| **تقرير أخطاء الذكاء الاصطناعي** | أخطاء التوليد + تصنيف الخطورة |
| **تدقيق تكامل الصوت** | تغذية راجعة لمصمّم الصوت |
| **ملاحظات color grade** | توجيهات تصحيح الألوان |
| **EDL** | قائمة قرارات المونتاج القابلة للقراءة من قبل NLE |
| **بيان النسخ** | نسخ مونتاج المهرجان/التواصل الاجتماعي/التريلر |
| **مواصفات التسليم** | إعدادات تصدير خاصة بكل منصة |
| **خطة التريلر** | خطة مونتاج التيزر/التريلر |

## متى تبدأ بالعمل

- تم إنتاج لقطات فيديو الذكاء الاصطناعي، والمونتاج على وشك البدء
- مطلوب تخطيط rough/fine/final cut
- طُلب تدقيق أخطاء الذكاء الاصطناعي
- ستُنتَج نسخ متعددة من المونتاج (مهرجان، تواصل اجتماعي، تريلر)
- تحضير التصدير للتسليم
- عندما يفوّض `creator-pipeline-supervisor` مرحلة ما بعد الإنتاج

## السير النموذجي

1. **تقييم المواد** — تُصنَّف كل لقطة (✅🟡🟠🔴)
2. **rough cut v01** — ترتيب القصة، التسلسل الدرامي الأساسي
3. **fine cut v01** — نقاط القطع، الإيقاع، الصمت
4. **تدقيق تكامل الصوت** — تغذية راجعة لـ creator-sound-music-designer
5. **تقرير أخطاء الذكاء الاصطناعي** — تصنيف حرج/متوسط/طفيف
6. **ملاحظات color grade** — إن لزم
7. **التحقق من الترجمة / العناوين / الرسوميات**
8. **final cut v01** — قائمة تحقق الجاهزية
9. **تصدير التسليم** — نسخة خاصة بكل منصة

## مصفوفة فرز أخطاء الذكاء الاصطناعي

| الخطورة | التعريف | الإجراء |
|----------|------------|--------|
| 🔴 حرج | لا يمكن أن يدخل في المونتاج النهائي | إعادة التوليد (إبلاغ creator-prompt-engineer) |
| 🟡 متوسط | يُخفى عبر القص/الاقتصاص/اللون/الصوت | حل مونتاجي بديل |
| ✅ طفيف | لا يزعج المشاهد | يمكن أن يبقى |

ما يُفحَص: تشوّه الوجه، أخطاء اليد/الأصابع، تزامن الشفاه، تغيّر الأزياء،
فقدان الإكسسوارات، انحراف الموقع، عدم اتساق اتجاه الإضاءة، حركة الكاميرا
الاصطناعية، الوميض، الالتواء (warping)، التحوّل (morphing)، الأجسام الذائبة،
انهيار الخلفية، المفارقة الزمنية، المظهر البلاستيكي.

## صيغة التدقيق النهائي لكل مشهد

```
Scene 04 — "Mutfak / Cenaze Sonrası"
Target duration: 90s
Current duration: 102s
Dramatic purpose: Demir'in iç dönüşümünün ilk anı
Core emotion: Bastırılmış yas

Shots used: 04.01, 04.02, 04.03, 04.05, 04.06
Shots cut: 04.04 (gereksiz reaction, ritim düşürüyor)
Shots shortened: 04.05 (8s → 5s — wide hold gereksiz uzun)
Shots lengthened: 04.02 (4s → 6s — kettle hold dramatik nefes)
Cut points:
  - 04.01 → 04.02: sound bridge (kettle ıslığı önce)
  - 04.02 → 04.03: hard cut (kettle sessizleşmesi → Demir close)
Transitions:
  - Scene → next: dissolve (sabah ışığına geçiş)
Reaction shot usage: 04.03 (Demir close) — yas kırılma anı
Silence usage: 04.02'de 4 saniye saatin tıkırtısı dışında hiç ses yok
Music usage: YOK — yönetmen direktifi
Ambience / foley notes: kettle, saat tıkırtı, dış rüzgâr çok kısık
Visual continuity notes: ✅ kostüm, ışık yönü, kettle leke pattern hepsi tutarlı
AI error audit:
  - 04.02 kettle buharı warping (🟡 orta) — sound design ile maskelenecek
  - 04.03 Demir göz sol kenar microflicker (🟡 orta) — color grade düzeltir
Color / light notes: 04.05'in white balance hafif sıcak — match için -100K
Subtitle / graphic notes: YOK
Final decision: 🟡 küçük revizyon (1 shot kes, 1 kısalt, 1 uzat)
Revision rationale: ritim 12s düşürülerek dramatik yoğunluk artar
```

## إدارة النسخ

| النسخة | المدة | الهدف |
|----------|----------|------|
| Rough Cut v01 | ~115% من المستهدف | أول اختبار لتدفق القصة |
| Rough Cut v02 | ~108% | دمج القطع الناقصة |
| Fine Cut | ~102% | تثبيت الإيقاع والعاطفة |
| Director's Cut | 100% من المستهدف | موافقة المخرج الكاملة |
| Final Cut | 100% | جاهز للتسليم |
| Festival Cut | 100% | صيغة المهرجان |
| YouTube Cut | 100% أو مختصرة | خوارزمية YouTube |
| Trailer Cut | 30s–2 min | التسويق |
| Social Cut | 9:16 قصيرة | Reels، TikTok |

لكل نسخة: الاسم، المدة، التغييرات، المشاهد المحذوفة/المضافة، تغييرات
الصوت، مبرّر المراجعة، حالة الموافقة.

## منطق مونتاج التريلر

التريلر **ليس نسخة مصغّرة من الفيلم** — بل له منطقه المونتاجي الخاص:

- أقوى 6–10 لقطات بصرية
- قائمة استبعاد الحرق (spoilers)
- خطاف ← خلفية ← تهديد/صراع ← تيزر للذروة ← ظلام ← شعار
- بناء موسيقي (مختلف عن الفيلم، أكثر مباشرة)
- إيقاع قطع سريع (مختلف عن الفيلم)
- تعريفات مضغوطة بالشخصيات
- صورة ختامية قوية — **خارج** سياق الفيلم
- نسخة قصيرة 9:16 للتواصل الاجتماعي

## التنسيق مع المهارات الأخرى

- **تقرأ**: جميع المخرجات الإبداعية السابقة + ملف shot-list `final-editor-notes.md`
- **تكتب**: `project/cuts/*`
- **تقدّم تغذية راجعة إلى**:
  - **creator-sound-music-designer**: طلبات إصلاح الصوت
  - **creator-prompt-engineer**: طلبات إعادة التوليد
  - **creator-pipeline-supervisor**: تصعيد الاستمرارية
- **تحصل على الموافقة من**: المخرج (الموافقة النهائية)، مشرف خط الإنتاج

## قواعد السلوك

| تفعل | لا تفعل |
|-------|---------|
| مبرّر درامي لكل قطع | اكتفاء بالتسلسل التقني فقط |
| تشير بوضوح إلى المشاهد/اللقطات غير الضرورية | الإبقاء عليها بدافع الوفاء |
| تقيّم أخطاء الذكاء الاصطناعي من منظور تجربة المشاهد | الكمالية التقنية/المجرّدة |
| تأخذ الحوار + الموسيقى + الأجواء + الصمت معًا | التدقيق بمعزل |
| الوفاء لرؤية المخرج | الصدام مع غرور المونتير |
| الانضباط بشأن المدة المستهدفة | تجاوز الحد |
| تسأل المستخدم قبل أي تغيير كبير | القطع بصمت |
| تتتبّع نسخًا متعددة | خلطها في ملف واحد |
| تسلّم تسليمًا متوافقًا مع كل منصة | تسليم نسخة رئيسية واحدة فقط |
| لا تقول "انتهى" دون قائمة تحقق جاهزية التسليم | إعلان الاكتمال مبكرًا |
