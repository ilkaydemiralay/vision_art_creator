# फ़ाइनल कट एडिटर — `creator-final-cut-editor`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · **हिन्दी** · [العربية](README.ar.md) · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Русский](README.ru.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

वह स्किल जो AI प्रोडक्शन के आउटपुट को एक **तैयार फ़िल्म** में बदल देती है। प्री-प्रोडक्शन का अंत / पोस्ट-प्रोडक्शन की शुरुआत। एक बार मटेरियल तैयार हो जाने पर, यह
rough cut → fine cut → final cut → डिलीवरी की प्रक्रिया को संभालती है; यह AI
जनरेशन की त्रुटियों की छँटाई करती है, निरंतरता का ऑडिट करती है, ऑडियो/म्यूज़िक इंटीग्रेशन की जाँच करती है, और
डिलीवरी के लिए तैयार मास्टर तैयार करती है।

**shot-list-designer से अंतर**: शॉट लिस्ट शूट से पहले एडिटोरियल इरादे को डिज़ाइन करती है;
creator-final-cut-editor असल मटेरियल पर कट को EXECUTE करता है।

## दर्शन

फ़ाइनल कट कोई **तकनीकी अनुक्रमण नहीं** है — यह सिनेमाई समग्रता का
निर्माण है। यह स्किल:

- **हर कट के लिए एक नाटकीय औचित्य** — "अच्छा दिखता है" काफ़ी नहीं
- **बहु-स्तरीय लय**: एक शॉट के भीतर, एक सीन के भीतर, पूरी फ़िल्म में
- **AI त्रुटि की छँटाई**: कौन-सी त्रुटि कट को तोड़ती है, कौन-सी छुपाई जा सकती है, कौन-सी रह सकती है
- **दर्शक अनुभव का डिज़ाइन**: दर्शक क्या महसूस करता है, क्या सीखता है, और क्या लेकर जाता है
- **डिलीवरी अनुशासन**: YouTube ≠ फ़ेस्टिवल ≠ Instagram ≠ आर्काइव
- **वर्ज़निंग**: rough/fine/final + फ़ेस्टिवल/सोशल/ट्रेलर कट को अलग-अलग संभालती है

## यह क्या करती है

| आउटपुट | विषयवस्तु |
|-------|---------|
| **मटेरियल मूल्यांकन** | प्रति शॉट: उपयोग योग्य / संशोधन / पुनः-जनरेट / कट |
| **रफ़ कट प्लान** | पहला रफ़ अनुक्रमण, छूटे हुए मटेरियल की सूची |
| **फ़ाइन कट प्लान** | कट पॉइंट, शॉट अवधि, मौन |
| **फ़ाइनल कट प्लान** | अंतिम तैयारी + डिलीवरी चेकलिस्ट |
| **प्रति-सीन फ़ाइनल-चेक** | विस्तृत सीन-दर-सीन ऑडिट |
| **पूरी-फ़िल्म रिपोर्ट** | पूरी फ़िल्म के लिए फ़ाइनल कट रिपोर्ट |
| **AI त्रुटि रिपोर्ट** | जनरेशन त्रुटियाँ + गंभीरता वर्गीकरण |
| **ऑडियो इंटीग्रेशन ऑडिट** | साउंड डिज़ाइनर को फ़ीडबैक |
| **कलर ग्रेड नोट्स** | कलर करेक्शन निर्देश |
| **EDL** | NLE-पठनीय Edit Decision List |
| **वर्ज़न मैनिफ़ेस्ट** | फ़ेस्टिवल/सोशल/ट्रेलर कट वर्ज़न |
| **डिलीवरी स्पेक्स** | प्लेटफ़ॉर्म-विशिष्ट एक्सपोर्ट सेटिंग्स |
| **ट्रेलर प्लान** | टीज़र/ट्रेलर कट प्लान |

## यह कब सक्रिय होती है

- AI वीडियो शॉट तैयार हो चुके हैं, एडिटिंग शुरू हो रही है
- रफ़/फ़ाइन/फ़ाइनल कट प्लानिंग की आवश्यकता है
- एक AI त्रुटि ऑडिट का अनुरोध किया गया है
- कई कट (फ़ेस्टिवल, सोशल, ट्रेलर) तैयार किए जाएँगे
- डिलीवरी एक्सपोर्ट की तैयारी
- जब `creator-pipeline-supervisor` पोस्ट-प्रोडक्शन चरण सौंपता है

## सामान्य प्रवाह

1. **मटेरियल मूल्यांकन** — हर शॉट को वर्गीकृत किया जाता है (✅🟡🟠🔴)
2. **रफ़ कट v01** — कहानी का क्रम, बुनियादी नाटकीय अनुक्रम
3. **फ़ाइन कट v01** — कट पॉइंट, लय, मौन
4. **साउंड इंटीग्रेशन ऑडिट** — creator-sound-music-designer को फ़ीडबैक
5. **AI त्रुटि रिपोर्ट** — critical/medium/minor वर्गीकरण
6. **कलर ग्रेड नोट्स** — यदि आवश्यक हो
7. **सबटाइटल / टाइटल / ग्राफ़िक्स जाँच**
8. **फ़ाइनल कट v01** — तैयारी चेकलिस्ट
9. **डिलीवरी एक्सपोर्ट** — प्लेटफ़ॉर्म-विशिष्ट वर्ज़न

## AI त्रुटि छँटाई मैट्रिक्स

| गंभीरता | परिभाषा | कार्रवाई |
|----------|------------|--------|
| 🔴 Critical | फ़ाइनल कट में नहीं आ सकती | पुनः-जनरेट (creator-prompt-engineer को फ़्लैग करें) |
| 🟡 Medium | ट्रिम/क्रॉप/कलर/साउंड के ज़रिए छुपाई गई | एडिटोरियल वर्कअराउंड |
| ✅ Minor | दर्शक को परेशान नहीं करती | रह सकती है |

जाँचा गया: चेहरे की विकृति, हाथ/उँगली की त्रुटियाँ, lip-sync, कॉस्ट्यूम बदलाव,
एक्सेसरीज़ का नुकसान, लोकेशन ड्रिफ़्ट, प्रकाश-दिशा की असंगति, कृत्रिम
कैमरा मूवमेंट, फ़्लिकर, वार्पिंग, मॉर्फ़िंग, पिघलती वस्तुएँ, बैकग्राउंड
ब्रेकडाउन, कालविरोध, प्लास्टिक जैसा लुक।

## प्रति-सीन फ़ाइनल-चेक प्रारूप

```
Scene 04 — "Mutfak / Cenaze Sonrası"
Target duration: 90s
Current duration: 102s
Dramatic purpose: Demir'in iç dönüşümünün ilk anı
Core emotion: Bastırılmış yas

Shots used: 04.01, 04.02, 04.03, 04.05, 04.06
Shots cut: 04.04 (gereksiz reaction, ritim düşürüyor)
Shots shortened: 04.05 (8s → 5s — wide hold gereksiz uzun)
Shots lengthened: 04.02 (4s → 6s — kettle hold dramatik nefes)
Cut points:
  - 04.01 → 04.02: sound bridge (kettle ıslığı önce)
  - 04.02 → 04.03: hard cut (kettle sessizleşmesi → Demir close)
Transitions:
  - Scene → next: dissolve (sabah ışığına geçiş)
Reaction shot usage: 04.03 (Demir close) — yas kırılma anı
Silence usage: 04.02'de 4 saniye saatin tıkırtısı dışında hiç ses yok
Music usage: YOK — yönetmen direktifi
Ambience / foley notes: kettle, saat tıkırtı, dış rüzgâr çok kısık
Visual continuity notes: ✅ kostüm, ışık yönü, kettle leke pattern hepsi tutarlı
AI error audit:
  - 04.02 kettle buharı warping (🟡 orta) — sound design ile maskelenecek
  - 04.03 Demir göz sol kenar microflicker (🟡 orta) — color grade düzeltir
Color / light notes: 04.05'in white balance hafif sıcak — match için -100K
Subtitle / graphic notes: YOK
Final decision: 🟡 küçük revizyon (1 shot kes, 1 kısalt, 1 uzat)
Revision rationale: ritim 12s düşürülerek dramatik yoğunluk artar
```

## ट्रेलर कट तर्क

एक ट्रेलर **फ़िल्म का लघुरूप नहीं** है — इसका अपना एडिटोरियल तर्क होता है:

- 6–10 सबसे दमदार दृश्य
- स्पॉइलर बहिष्करण सूची
- हुक → पृष्ठभूमि → ख़तरा/संघर्ष → क्लाइमैक्स टीज़र → अँधेरा → टैगलाइन
- म्यूज़िक बिल्ड (फ़िल्म से अलग, अधिक सीधा)
- तेज़ कटिंग लय (फ़िल्म से अलग)
- संक्षिप्त किरदार परिचय
- एक अंतिम पंच इमेज — फ़िल्म के संदर्भ के **बाहर**
- छोटा सोशल मीडिया 9:16 वर्ज़न

## अन्य स्किल्स के साथ समन्वय

- **पढ़ती है**: सभी अपस्ट्रीम क्रिएटिव आउटपुट + shot-list `final-editor-notes.md`
- **लिखती है**: `project/cuts/*`
- **फ़ीडबैक देती है**:
  - **creator-sound-music-designer**: ऑडियो फ़िक्स अनुरोध
  - **creator-prompt-engineer**: पुनर्जनन अनुरोध
  - **creator-pipeline-supervisor**: निरंतरता एस्केलेशन
- **स्वीकृति लेती है**: निर्देशक (अंतिम स्वीकृति), Pipeline Supervisor

## व्यवहार नियम

| करती है | नहीं करती |
|-------|---------|
| हर कट के लिए एक नाटकीय औचित्य | केवल तकनीकी अनुक्रमण करना |
| अनावश्यक सीन/शॉट को स्पष्ट रूप से फ़्लैग करती है | निष्ठा के नाम पर उन्हें रखना |
| AI त्रुटियों का मूल्यांकन दर्शक अनुभव से करती है | अमूर्त/तकनीकी पूर्णतावाद |
| संवाद + म्यूज़िक + एम्बिएंस + मौन को एक साथ देखती है | अलग-अलग ऑडिट करना |
| निर्देशक के दृष्टिकोण के प्रति निष्ठावान | एडिटोरियल अहंकार से टकराना |
| लक्षित अवधि को लेकर अनुशासित | सीमा से अधिक चले जाना |
| बड़े बदलाव से पहले उपयोगकर्ता से पूछती है | चुपचाप कट करना |
| कई वर्ज़न ट्रैक करती है | उन्हें एक ही फ़ाइल में मिलाना |
| प्लेटफ़ॉर्म-अनुकूल डिलीवरी प्रदान करती है | केवल एक मास्टर सौंपना |
| डिलीवरी तैयारी चेकलिस्ट के बिना "हो गया" नहीं कहेगी | समय से पहले इसे पूर्ण घोषित करना |
