# Монтажёр финального монтажа — `creator-final-cut-editor`

[English](README.md) · [中文](README.zh.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português (BR)](README.pt-BR.md) · [Türkçe](README.tr.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · **Русский** · [日本語](README.ja.md) · [한국어](README.ko.md)

Навык, превращающий результаты AI-производства в **готовый фильм**. Конец
препродакшена / начало постпродакшена. Как только материал произведён, он
управляет потоком rough cut → fine cut → final cut → доставка; сортирует ошибки
AI-генерации, проверяет непрерывность, контролирует интеграцию аудио/музыки и
создаёт готовые к доставке мастер-копии.

**Отличие от shot-list-designer**: shot list проектирует монтажный замысел
ДО съёмки; creator-final-cut-editor ВЫПОЛНЯЕТ монтаж на реальном материале.

## Философия

Финальный монтаж — это **не техническое выстраивание последовательности**, это
конструирование кинематографической цельности. Этот навык:

- **Драматургическое обоснование каждой склейки** — «выглядит хорошо» недостаточно
- **Многомасштабный ритм**: внутри кадра, внутри сцены, через весь фильм
- **Сортировка ошибок AI**: какая ошибка ломает монтаж, какую можно скрыть, какая может остаться
- **Проектирование зрительского опыта**: что зритель чувствует, узнаёт и уносит с собой
- **Дисциплина доставки**: YouTube ≠ фестиваль ≠ Instagram ≠ архив
- **Версионирование**: отдельно ведёт rough/fine/final + фестивальный/социальный/трейлерный монтаж

## Что он делает

| Результат | Содержание |
|-------|---------|
| **Оценка материала** | По каждому кадру: годен / доработать / перегенерировать / вырезать |
| **План rough cut** | Первая черновая раскадровка, список недостающего материала |
| **План fine cut** | Точки склейки, длительности кадров, паузы |
| **План final cut** | Финальная готовность + чек-лист доставки |
| **Финальная проверка по сценам** | Детальный посценовый аудит |
| **Отчёт по всему фильму** | Отчёт о финальном монтаже всего фильма |
| **Отчёт об ошибках AI** | Ошибки генерации + классификация по серьёзности |
| **Аудит интеграции аудио** | Обратная связь саунд-дизайнеру |
| **Заметки по цветокоррекции** | Директивы по color correction |
| **EDL** | Edit Decision List, читаемый NLE |
| **Манифест версий** | Версии фестивального/социального/трейлерного монтажа |
| **Спецификации доставки** | Настройки экспорта под конкретную платформу |
| **План трейлера** | План тизерного/трейлерного монтажа |

## Когда он включается

- AI-видеокадры произведены, начинается монтаж
- Требуется планирование rough/fine/final cut
- Запрошен аудит ошибок AI
- Будут произведены несколько монтажей (фестивальный, социальный, трейлер)
- Подготовка к экспорту для доставки
- Когда `creator-pipeline-supervisor` делегирует фазу постпродакшена

## Типичный поток

1. **Оценка материала** — каждый кадр категоризируется (✅🟡🟠🔴)
2. **Rough cut v01** — порядок истории, базовая драматургическая последовательность
3. **Fine cut v01** — точки склейки, ритм, паузы
4. **Аудит интеграции звука** — обратная связь creator-sound-music-designer
5. **Отчёт об ошибках AI** — классификация критическая/средняя/незначительная
6. **Заметки по цветокоррекции** — при необходимости
7. **Проверка субтитров / титров / графики**
8. **Final cut v01** — чек-лист готовности
9. **Экспорт для доставки** — версия под конкретную платформу

## Матрица сортировки ошибок AI

| Серьёзность | Определение | Действие |
|----------|------------|--------|
| 🔴 Критическая | Не может попасть в финальный монтаж | Перегенерировать (отметить creator-prompt-engineer) |
| 🟡 Средняя | Скрывается через trim/crop/цвет/звук | Монтажный обходной приём |
| ✅ Незначительная | Не мешает зрителю | Может остаться |

Проверяется: искажение лица, ошибки рук/пальцев, lip-sync, изменения костюма,
потеря аксессуаров, дрейф локации, несогласованность направления света,
искусственное движение камеры, мерцание, warping, морфинг, плавящиеся объекты,
распад фона, анахронизм, пластиковый вид.

## Формат финальной проверки по сценам

```
Scene 04 — "Mutfak / Cenaze Sonrası"
Target duration: 90s
Current duration: 102s
Dramatic purpose: Demir'in iç dönüşümünün ilk anı
Core emotion: Bastırılmış yas

Shots used: 04.01, 04.02, 04.03, 04.05, 04.06
Shots cut: 04.04 (gereksiz reaction, ritim düşürüyor)
Shots shortened: 04.05 (8s → 5s — wide hold gereksiz uzun)
Shots lengthened: 04.02 (4s → 6s — kettle hold dramatik nefes)
Cut points:
  - 04.01 → 04.02: sound bridge (kettle ıslığı önce)
  - 04.02 → 04.03: hard cut (kettle sessizleşmesi → Demir close)
Transitions:
  - Scene → next: dissolve (sabah ışığına geçiş)
Reaction shot usage: 04.03 (Demir close) — yas kırılma anı
Silence usage: 04.02'de 4 saniye saatin tıkırtısı dışında hiç ses yok
Music usage: YOK — yönetmen direktifi
Ambience / foley notes: kettle, saat tıkırtı, dış rüzgâr çok kısık
Visual continuity notes: ✅ kostüm, ışık yönü, kettle leke pattern hepsi tutarlı
AI error audit:
  - 04.02 kettle buharı warping (🟡 orta) — sound design ile maskelenecek
  - 04.03 Demir göz sol kenar microflicker (🟡 orta) — color grade düzeltir
Color / light notes: 04.05'in white balance hafif sıcak — match için -100K
Subtitle / graphic notes: YOK
Final decision: 🟡 küçük revizyon (1 shot kes, 1 kısalt, 1 uzat)
Revision rationale: ritim 12s düşürülerek dramatik yoğunluk artar
```

## Управление версиями

| Версия | Длительность | Цель |
|----------|----------|------|
| Rough Cut v01 | ~115% от цели | Первая проверка течения истории |
| Rough Cut v02 | ~108% | Интеграция недостающих фрагментов |
| Fine Cut | ~102% | Фиксация ритма и эмоции |
| Director's Cut | 100% от цели | Полное одобрение режиссёра |
| Final Cut | 100% | Готов к доставке |
| Festival Cut | 100% | Фестивальный формат |
| YouTube Cut | 100% или укороченная | Алгоритм YouTube |
| Trailer Cut | 30s–2 min | Маркетинг |
| Social Cut | 9:16 короткая | Reels, TikTok |

Для каждой версии: имя, длительность, изменения, удалённые/добавленные сцены,
изменения аудио, обоснование ревизии, статус одобрения.

## Логика трейлерного монтажа

Трейлер — это **не миниатюра фильма**, у него своя монтажная логика:

- 6–10 самых сильных визуалов
- Список исключения спойлеров
- Зацепка → предыстория → угроза/конфликт → тизер кульминации → темнота → слоган
- Музыкальное нарастание (отличается от фильма, более прямое)
- Быстрый монтажный ритм (отличается от фильма)
- Сжатые представления персонажей
- Финальный ударный кадр — **вне** контекста фильма
- Короткая версия 9:16 для соцсетей

## Координация с другими навыками

- **Читает**: все выходные данные творческих департаментов выше по потоку + `final-editor-notes.md` из shot-list
- **Пишет**: `project/cuts/*`
- **Даёт обратную связь**:
  - **creator-sound-music-designer**: запросы на исправление аудио
  - **creator-prompt-engineer**: запросы на перегенерацию
  - **creator-pipeline-supervisor**: эскалация по непрерывности
- **Получает одобрение от**: режиссёра (финальное одобрение), Pipeline Supervisor

## Правила поведения

| Делает | Не делает |
|-------|---------|
| Драматургическое обоснование каждой склейки | Сугубо техническое выстраивание последовательности |
| Чётко отмечает лишние сцены/кадры | Сохраняет их из чувства лояльности |
| Оценивает ошибки AI с точки зрения зрительского опыта | Абстрактный/технический перфекционизм |
| Рассматривает диалог + музыку + амбиент + паузы вместе | Аудит в изоляции |
| Верен видению режиссёра | Конфликт с монтажным эго |
| Дисциплинирован в отношении целевой длительности | Превышает лимит |
| Спрашивает пользователя перед крупным изменением | Режет молча |
| Отслеживает несколько версий | Смешивает их в одном файле |
| Доставляет под формат платформы | Передаёт единый мастер |
| Не скажет «готово» без чек-листа готовности к доставке | Объявляет завершённым раньше срока |
